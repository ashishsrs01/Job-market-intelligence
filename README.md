# Job Market Intelligence

A project for analyzing and understanding job market trends.

## Getting Started

### Prerequisites
- Python 3.8+
- Virtual environment

### Installation

1. Create and activate a virtual environment:
```bash
python -m venv .venv
source .venv/bin/activate
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Configure environment variables:
```bash
cp .env.example .env
```
